## How to Upload Your Logo

1. **Via FTP/SFTP:**
   - Upload your logo file to: `/var/www/Logistics-Management-System/public/images/s2e-logo.png`

2. **Via File Manager:**
   - Navigate to `public/images/` directory
   - Upload `s2e-logo.png` file

3. **Via Command Line:**
   ```bash
   cd /var/www/Logistics-Management-System/public/images/
   # Upload your logo file here
   ```
