========================================
RECOMMENDED SOLUTION: Install Laragon
========================================

Laragon is the EASIEST option - it includes everything:
✅ PHP (multiple versions)
✅ MySQL Server
✅ Composer
✅ Easy database management
✅ One-click start/stop

DOWNLOAD: https://laragon.org/download/

After installing Laragon:
1. Start Laragon
2. Open Terminal in Laragon
3. Navigate to: cd "C:\Users\Murtaza Lapi\Desktop\Logistic"
4. Run: composer install
5. Run: php artisan key:generate
6. Create database: logistics_db (in Laragon)
7. Run: php artisan migrate
8. Run: php artisan db:seed
9. Run: php artisan serve
10. Open: http://localhost:8000
